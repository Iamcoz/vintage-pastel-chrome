# Vintage Pastel 크롬 테마

빈티지 파스텔 색감(라벤더, 세이지 민트, 풍선 분홍, 아이보리)으로 만든 구글 크롬 테마와 새 탭 확장.

- 창 틀: 하늘색 수건 `#BCCBE0`(비활성일 때도 같은 색), 뒤쪽 탭 글자 `#E3DFC4`
- 탭과 툴바: 분홍 풍선 `#E9B3BA`, 글자 `#EFECDC`, 아이콘 `#859E7A`
- 주소창: 노랑 풍선 `#E6DDA4`. 단, 지금 크롬은 이 색을 주소를 칠 때 펼쳐지는 추천 목록에만 쓰고, 주소창 칸 자체는 툴바 색을 밝게 만든 색(분홍 `#F2D4D7`)으로 자동으로 칠한다
- 새 탭: 세이지 민트 `#B7CBA9`, 글자 `#E6DDA4`
- 글자를 일부러 배경과 비슷한 밝은 색으로 맞춰서 탭 제목, 주소, 북마크 글자가 흐리게 보인다

## 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** 클릭
4. 이 폴더(`chrome-theme`) 선택

바로 테마가 바뀐다. 적용된 테마는 `chrome://settings/appearance`의 **테마** 줄에서 확인할 수 있다.

## 새 탭 화면(노란 검색창)
크롬 기본 새 탭의 가운데 검색창은 테마로 색을 바꿀 수 없어서(항상 흰색), 새 탭 화면 자체를 바꾸는 확장을 따로 두었다. `newtab` 폴더가 그 확장이다.

- 화면: 세이지 민트 배경, 크롬 새 탭 로고 자리에 노란 `iamcoz` 글자(Google Sans 글꼴), 툴바와 같은 분홍 검색창(Google 검색). 로고와 검색창의 크기, 위치는 크롬 기본 새 탭과 같다. 탭 아이콘은 비워 둔다
- 검색창은 크롬 기본 새 탭과 같은 모양(+, 입력칸, 마이크, 렌즈, AI 모드)이고 색만 테마 색이다. +와 AI 모드는 Google AI 모드를, 렌즈는 Google 렌즈를 열고, 마이크는 크롬 음성 인식으로 듣고 바로 검색한다
- 검색창 모양 바꾸기(분홍 / 투명): `chrome://extensions` → 이 확장의 **세부정보** → **확장 프로그램 옵션**
- 아래쪽 바닥글(확장 이름 표시)은 확장이 끌 수 없다. 바닥글을 오른쪽 클릭해서 숨기기 메뉴를 고른다
- 설치: 위 설치 1~3단계 후 4단계에서 이 폴더 안의 `newtab` 폴더를 선택한다. 테마와 별개 확장이라 둘 다 로드해 둔다.
- 처음 새 탭을 열면 크롬이 "이 확장 프로그램이 새 탭 페이지를 변경했습니다"라고 묻는다. **변경사항 유지**를 누른다.
- 새 탭을 열면 글자 입력 위치는 검색창이 아니라 주소창에 있다(크롬이 확장 새 탭에 입력 위치를 주지 않는다). 검색창을 한 번 누르고 입력한다.
- 다시 로드하는 법: `chrome://extensions`의 이 확장 카드에서 새로고침 아이콘을 누른 뒤 새 탭을 다시 연다.
- 크롬 기본 새 탭의 바로가기는 없다. 되돌리려면 `chrome://extensions`에서 이 확장을 끄거나 삭제한다.

## 제거(기본 테마로 되돌리기)
`chrome://settings/appearance` → **테마** 줄의 **기본값으로 재설정**.

## 고친 뒤 다시 적용하기
`manifest.json`을 고친 뒤 위 설치 1~4단계를 한 번 더 한다(같은 폴더를 다시 로드하면 새 내용으로 덮어쓴다).

## 알아 둘 것
- 새 탭의 Google 로고와 바로가기 동그라미 색, 가운데 흰 검색창은 크롬과 Google이 정한다. 로고와 동그라미는 새 탭 배경색에서 자동으로 만든 진한 초록이 된다.
- 맥의 왼쪽 위 빨강, 노랑, 초록 버튼은 macOS가 그리는 버튼이라 크롬 테마로 색을 바꿀 수 없다.
- 시크릿 창 색은 따로 정하지 않았다. 크롬이 창 틀 색으로 알아서 만든다.
